Funktionen von InStaff

Mitarbeiterverwaltung

Alle Mitarbeiter und Aushilfskräfte zentral verwalten, Profile bearbeiten und Rollen organisieren.

Schichtplanung

Manager können Schichten erstellen, bearbeiten und gezielt Aushilfskräfte dafür anfragen.

Schichtanfragen

Aushilfskräfte erhalten Schichtanfragen und können diese direkt annehmen oder ablehnen.

Manager Tools

Überblick über verfügbare Aushilfen, offene Anfragen und aktuelle Schichtbesetzungen.

Mobile App für Aushilfen

Aushilfen können Schichtanfragen direkt über die mobile App annehmen oder ablehnen.

Kalenderübersicht

Alle geplanten Schichten übersichtlich im Kalender anzeigen, Details öffnen und Änderungen direkt vornehmen. So behalten Manager jederzeit den Überblick über verfügbare und besetzte Schichten.
